# Change Log

All notable changes to the "amdgcn-asm" extension will be documented in this file.

## [0.1.0] - 2025-11-16

### Added
- Initial release
- Syntax highlighting for AMDGCN assembly language
- Support for scalar instructions (s_*)
- Support for vector instructions (v_*)
- Support for flat, global, scratch, DS, buffer, and image instructions
- Register highlighting (scalar, vector, AGPR, special registers)
- Directive highlighting (.section, .globl, .set, etc.)
- Comment support (line and block comments)
- Number literal highlighting (hex, binary, octal, decimal)
- Label and function name highlighting
- Auto-closing pairs and brackets
- Code folding support
